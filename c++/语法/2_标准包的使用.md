# 1 std::optional

**作用**: 用于表达“一个值可能存在，也可能不存在”，且这种“不存在”是类型安全、语义清晰的。

**使用**：

引用包： `#include <optional>`

<font color=green>**判空方式**</font>: 
```c++
if (v.has_value()) {
    // or if (v)
}
```

<font color=green>**取值方式**</font>：
|方式|	特点|
|----|-----|
|*v|	简洁，但需确保有值|
|v.value()|	无值时抛异常|
|v.value_or(0)|	推荐：提供默认值|

**和指针的本质区别**

`int* p = nullptr;`表示“地址是否存在”, 暗示动态内存, 语义不清

`std::optional<int> v;`表示“值是否存在”, 不涉及内存管理, 语义明确
>如果你表达的是“有没有这个值”，而不是“有没有这个对象”，就用 optional。

<font color=green>**延迟初始化**</font>：
```c++
std::optional<Socket> sock;

if (connected) {
    sock.emplace(fd);
}
```

<font color=green>**什么时候不该用 optional**</font>：

|不适合的场景|	原因|
|----|------|
|性能极端敏感|	多一个分支|
|成员几乎总是存在|	多余|
|表示“错误原因”|	用 expected|

<font color=green>**optional 对比 unique_ptr**</font>：

|对比项|	optional|	unique_ptr|
|------|-----------|--------------|
|是否动态分配|	否|	是|
|表达含义|	值存在与否|	所有权|
|适合 POD|	✔|	❌|
|可空语义|	✔|	✔|


**示例**：
```c++
#include <iostream>
#include <optional>

std::optional<int> GetValue(int a) {
    if (a > 10){
        return a;
    }
    return std::nullopt;
}

int main() {
    std::optional<int> v = GetValue(10);
    if (v.has_value()) {
        std::cout << *v << "\n";
    }else {
        std::cout << "not exist" << "\n";
    }
}
```

<a id="find"></a>

<font size=3 color=red>**查找子字符串**</font>:

<font color=#ef4400>**函数原型-1**</font>:

 `size_t find(const basic_string& __str, size_type __pos = 0) const`

 <font color=green>**函数作用**</font>： 查找__str中的第一个匹配的子字符串的位置索引。从__pos处开始查找

 |参数|作用|
 |----|----|
 |__str|需要寻找的子字符串|
 |pos|开始寻找的地方，0表示从字符串的第一个字符开始查找|

 <font color=green>**返回值**</font>:

 返回子字符串的第一个字符在目标字符串中的索引，
 例如下面的字符串"apple"对应的pos索引：

 |字符串|a|p|p|l|e|
 |------|-|-|-|-|-|
 |pos索引|0|1|2|3|4|

 如果返回值等于`std::string::npos`说明没有找到匹配的子字符串。

 <font color=green>**示例**</font>：

 ```c++
 #include <string>

 // 判断str中是否包含子字符串subStr
bool ContainsSubString(const std::string& str, const std::string& subStr){
    size_t pos = str.find(subStr, 0);
    return pos != std::string::npos;
}
 ```

---

 <font color=#ef4400>**函数原型-2**</font>:

 `size_t
      find(const _CharT* __s, size_type __pos, size_type __n) const`

 <font color=green>**函数作用**</font>： 从当前字符串的 __pos 位置开始，查找 __s 的前 __n 个字符组成的子串，返回第一次出现的位置。

 <font color=green>**示例**</font>：

 ```c++
    std::string str("2jake,apple");
    size_t pos = str.find("jake", 1, 3); // 查找str中"jak"字符串的位置
    printf("find=%d\n", pos!=std::string::npos);
 ```

 <a id="replace"></a>

<font size=3 color=red>**替换字符串**</font> 

<font color=green>**函数原型**</font> 

`basic_string& replace(size_type __pos, size_type __n1, const _CharT* __s)`

<font color=green>**作用**</font>： 

将原字符串从__pos开始的总共__n1个字符替换成__s， 并返回替换后的字符串，同时也会改变原字符串的值

<font color=green>**示例**</font>： 

```c++
std::string str("jake,apple");
std::string newStr = str.replace(0, 2, "999");
printf("原字符串:%s, 新字符串：%s\n", str.c_str(), newStr.c_str()); // 原字符串:999ke,apple, 新字符串：999ke,apple
```

<a id="append"></a>

<font size=3 color=red>**追加字符串**</font> 

<font color=green>**函数原型**</font> ：


<a id="compare"></a>

<font size=3 color=red>**字符串比较**</font> 

<font color=green>**函数原型**</font>

`int compare(const basic_string& __str) const`

<font color=green>**作用**</font>：比较两个字符串的大小。根据返回值来判断大小，返回-1，则说明自身小于目标字符串__str；如果返回0，说明等于目标字符串；如果返回1，说明自身大于目标字符串

<font color=green>**示例**</font>：

```c++
std::string str1("a");
std::string str2("b");
int result = str1.compare(str2);
// 可以近似理解为str1 - str2, 看结果与0的比较
printf("result：%d\n", result); // -1---> str1 < str12;  0-->str1 = str12 ; 1--> str1 > str12
```

<a id="comtains"></a>

<font size=3 color=red>**包含子字符串**</font> 

<font color=green>**函数原型**</font>

是否包含指定的子字符串：`constexpr bool contains(const _CharT* __x) const noexcept`

是否包含指定的字符：`constexpr bool contains(_CharT __x) const noexcept`

<font color=green>**示例**</font>

```c++
std::string str("apple");
// 判断是否包含字符串
if (str.contains("app")){
    printf("str中包含字符串app\n");
}

// 判断是否包含字符
if (str.contains('2')){
    printf("str中包含字符 '2'\n");
}
```
