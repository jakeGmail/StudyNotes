# 调用宏

Rust 宏是一种用来编写可生成代码的代码，从而扩展 Rust 语法的方式。

rust中通过`!`来表示调用宏，例如：

```rust
// 这是一个调用宏，而不是调用函数
println!("Hello World!");
```

# 声明变量

使用关键字`let`来声明变量，例如：

```rust
let name = "jake"; // 声明一个不可以修改值的变量

// 如果要让变量的值可以修改，需要使用 mut来修饰
let mut age = 2;

/*这里的::new说明new是String这个类型下的一个关联函数，后面还有许多类型
都提供了new这个函数*/
let mut gues = String::new(); // 需要引入 use std::io;
```

## 遮蔽

在声明变量的时候，我们可以使用let声明一个跟前面相同名称的变量，这样编译器在后面看到的这个名字的变量就是新let出的变量，直到新let出的变量的作用域结束

```rust
fn main() {
    let i = ""; // i是一个空字符串
    let i = 78 + 1; // 遮蔽前面的i变量
    println!("{:?}", i); // 79
    {
        let i = i + 2;
        println!("{:?}", i);
    }
    println!("{:?}", i);
}
```

## 格式化输出

通过println、print等终端输出函数是，打印变量可以使用`{}`来表示占位符,
在`{}`中间写变量名，表示输出变量的值。也可以`{}`中间留空来表示格式化输出。

```rust
fn main() {
    let name = "jake";
    print!("name={}: \n", name); // 格式化输出
    println!("名字为：{name}"); // 打印name变量的值
}
```


## 引用

在给函数传参时，使用`&`符号来表示传入的参数是变量的引用，它允许多处代码访问同一处数据，而无需在内存中多次拷贝。

```rust
let mut str = String::new();

/* 给read_line传参是，是用的str变量的引用， 为了使能够改变str的值，加上了mut修饰*/
io::stdin().read_line(&mut str).expect("Failed to read line");
```

fn main() {

## match语法

**使用match来比较**:

```rust
use rand::Rng;
use std::cmp::Ordering;
use std::io;

fn main() {
    println!("输入数字");
    let value = rand::thread_rng().random_range(1..=9);

    let mut input = String::new();
    io::stdin().read_line(&mut input).unwrap();

    let input: i32 = input.trim().parse().unwrap();

    // match的用法
    match input.cmp(&value) {
        Ordering::Less => {
            println!("大于");
        },
        Ordering::Equal => {
            println!("成功");
        },
        Ordering::Greater => {
            println!("小于");
        }
    }
}
```

**match用于处理Result**：

```rust
let mut input = String::new();
io::stdin().read_line(&mut input).unwrap();

/*因为parse()返回的是一个Result， 拥有 Ok 和 Err 成员的枚举，
因此这里使用match做判断，当出现Err时不再崩溃程序，而是忽略*/
let input: u32 = match input.trim().parse(){
    Ok(num) => num,
    Err(_) => continue,
};
```

# 循环

<font color=green>**loop循环**</font>:

loop循环的结构为：`loop {}`

```rust
use rand::Rng;
use std::cmp::Ordering;
use std::io;

fn main() {

    let value = rand::thread_rng().random_range(1..=100);

    // 循环
    loop {
        println!("输入数字:");
        let mut input = String::new();
        io::stdin().read_line(&mut input).unwrap();

        let input: i32 = input.trim().parse().unwrap();
        match input.cmp(&value) {
            Ordering::Less => {
                println!("猜小了");
                continue; // 继续循环
            },
            Ordering::Equal => {
                println!("成功");
                break; // 退出循环
            },
            Ordering::Greater => {
                println!("猜大了");
            },
        }
    }
}
```

# 结构体

<font size=3 color=green>**结构体的定义**</font>：

```rust
#[derive(Debug)] // 如果需要debug打印结构体的内容则需要添加这个标签，使用时通过println!("{<结构体变量名>:#?}");打印
struct Person{
    name: String,
    age: u8
}
```

<font size=3 color=green>**结构体方法**</font>：

通过在`impl <结构体名> {}`的大括号中间定义函数来给指定的结构体定义方法；


```rust
impl Person {
    fn Speak(&self) -> String{
        String::from("jake")
    }

    fn Contain(&self, p : &Person) -> bool {
        if self.age >= p.age {
            true
        }else {
            false
        }
    }


    fn See(name : String){
        println!("{}", name);
    }
}
```

对于第一个参数是`&self`的方法，调用时通过点来调用，例如`v1.Speak()`; 对于第一个参数不是`&self`的方法，通过冒号调用，例如`v1::See(&str0)`，这种方式通常用于定义成生成该结构体的构造方法。

<font size=3 color=green>**类单元结构体**</font>：

类单元结构体不存储任何数据，不占用空间。它本身是一个独立的类型，可以用于区分，对比单元结构`()`，这便是最大的区别。

```rust
// 定义一个类单元结构体
struct AA;

// 声明一个类单元结构体的变量
let aa = AA;
```

<font size=3 color=green>**元组结构体**</font>：

元组结构体与元组的区别就是元组结构体有自己的类型，在编程中可以区分语义。

```rust
// 元组结构体定义
struct Point(i32, i32);

// 访问数据方式
let p = Point(1, 2);
p.0;
p.1;
```

# match

<font size=3 color=green>**通过mathc来匹配**</font>

match的分支必须包含所有的可能性，不然会报错。

```rust
enum Coin{
    A,
    B,
    C,
    D
}

impl Coin{
    fn Value(&self) -> u8{
        match self {
            Coin::A => 1,
            Coin::B => {
                println!("value is B");
                2
            },
            Coin::C => 3,
            Coin::D => 4,
        }
    }
}
```

<font size=3 color=green>**绑定值模式**</font>

```rust
enum Coin{
    A,
    B,
    C(i32), // 绑定一个i32
    D
}

impl Coin{
    fn Value(&self) -> u8{
        match self {
            Coin::A => 1,
            Coin::B => 2,
            Coin::C(number) => {
                // number就是绑定到C上的值
                println!("value is C");
                return *number as u8;
            },
            Coin::D => 4,
        }
    }
}
```

<font size=3 color=green>**其他情形**</font>：

因为match要求必须包含所有可能的情形，如果我们仅希望处理部分，其他的情形采用默认行为，可以通过`other`或者`_`来匹配其他情形

```rust
// other的使用
fn Value(&self) -> u8{
    match self {
        Coin::C(number) => {
            println!("value is C");
            return *number as u8;
        },
        other =>  8, // 其他情况
    }
}


// _使用
let coin = Coin::A;
match coin {
    Coin::C(number) => {
        println!("value is C");
    },
    _ =>  (), // 其他情况， 告诉 Rust 我们不会使用与前面模式不匹配的值，并且这种情况下我们不想运行任何代码
}
```

<font size=3 color=green>**if let简化代码**</font>

if let 语法让我们以一种不那么冗长的方式结合 if 和 let，来处理只匹配一个模式的值而忽略其他模式的情况

```rust
let config_max = Some(3u8);
if let Some(max) = config_max {
    println!("The maximum is configured to be {max}");
}else{
    // 其他代码...   
}

// 上面那段代码等同于下面这段
let config_max = Some(3u8);
match config_max {
    Some(max) => println!("The maximum is configured to be {max}"),
    _ => (),
}
```

<font size=3 color=green>**let .. else语法**</font>

```rust
fn main() {
    let coin = Coin::C(34);
    println!("{}",describe_state_quarter(coin).is_none());
}

fn describe_state_quarter(coin: Coin) -> Option<String> {
    let Coin::C(state) = coin else {
        return None;
    };
    Some(state.to_string())
}

enum Coin{
    A,
    B,
    C(i32),
    D
}

```
