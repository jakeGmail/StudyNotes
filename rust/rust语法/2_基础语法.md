## 调用宏

Rust 宏是一种用来编写可生成代码的代码，从而扩展 Rust 语法的方式。

rust中通过`!`来表示调用宏，例如：

```rust
// 这是一个调用宏，而不是调用函数
println!("Hello World!");
```

## 声明变量

使用关键字`let`来声明变量，例如：

```rust
let name = "jake"; // 声明一个不可以修改值的变量

// 如果要让变量的值可以修改，需要使用 mut来修饰
let mut age = 2;

/*这里的::new说明new是String这个类型下的一个关联函数，后面还有许多类型
都提供了new这个函数*/
let mut gues = String::new(); // 需要引入 use std::io;
```

## 占位符

通过println、print等终端输出函数是，打印变量可以使用`{}`来表示占位符,
在`{}`中间写变量名，表示输出变量的值。也可以`{}`中间留空来表示格式化输出。

```rust
fn main() {
    let name = "jake";
    print!("name={}: \n", name); // 格式化输出
    println!("名字为：{name}"); // 打印name变量的值
}
```


## 引用

在给函数传参时，使用`&`符号来表示传入的参数是变量的引用，它允许多处代码访问同一处数据，而无需在内存中多次拷贝。

```rust
let mut str = String::new();

/* 给read_line传参是，是用的str变量的引用， 为了使能够改变str的值，加上了
mut修饰*/
io::stdin().read_line(&mut str).expect("Failed to read line");
```

## 类型转换

```rust
fn main() {
    let mut str = String::new();
    str = "123".to_string();

    // 将str这个变量转化为i32类型， 使用冒号+类型名
    // 冒号`:`告诉 Rust 我们指定了变量的类型
    let str: i32 = str.trim().parse().expect("could not parse");
}
```

## match语法

**使用match来比较**:

```rust
use rand::Rng;
use std::cmp::Ordering;
use std::io;

fn main() {
    println!("输入数字");
    let value = rand::thread_rng().random_range(1..=9);

    let mut input = String::new();
    io::stdin().read_line(&mut input).unwrap();

    let input: i32 = input.trim().parse().unwrap();

    // match的用法
    match input.cmp(&value) {
        Ordering::Less => {
            println!("大于");
        },
        Ordering::Equal => {
            println!("成功");
        },
        Ordering::Greater => {
            println!("小于");
        }
    }
}
```

**match用于处理Result**：

```rust
let mut input = String::new();
io::stdin().read_line(&mut input).unwrap();

/*因为parse()返回的是一个Result， 拥有 Ok 和 Err 成员的枚举，
因此这里使用match做判断，当出现Err时不再崩溃程序，而是忽略*/
let input: u32 = match input.trim().parse(){
    Ok(num) => num,
    Err(_) => continue,
};
```

## 循环

**loop循环**:

loop循环的结构为：`loop {}`

```rust
use rand::Rng;
use std::cmp::Ordering;
use std::io;

fn main() {

    let value = rand::thread_rng().random_range(1..=100);

    // 循环
    loop {
        println!("输入数字:");
        let mut input = String::new();
        io::stdin().read_line(&mut input).unwrap();

        let input: i32 = input.trim().parse().unwrap();
        match input.cmp(&value) {
            Ordering::Less => {
                println!("猜小了");
                continue; // 继续循环
            },
            Ordering::Equal => {
                println!("成功");
                break; // 退出循环
            },
            Ordering::Greater => {
                println!("猜大了");
            },
        }
    }
}
```
